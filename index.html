OSC setup

The browser sends tracked detections to the local bridge. The bridge sends UDP OSC to the host and port in the OSC panel.

/troloyolo/frame
frameId, count, width, height, timestamp, source
/troloyolo/object
frameId, id, classId, label, type, score, nx, ny, nw, nh, ncx, ncy, x, y, w, h
/troloyolo/test
timestamp, host, port

Normalized values are 0..1. Pixel values are in the source camera or media coordinate space.
